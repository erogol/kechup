# Security policy

## Supported versions

| Version | Supported |
|---|---|
| 1.0.x | yes |

## Report a vulnerability

Do not open a public issue for a security problem.

Report it in private on GitHub: open the **Security** tab of this repository and click **Report a vulnerability**. Or use this link: https://github.com/erogol/kechup/security/advisories/new

Include:

- the kechup version (`pip show kechup`),
- the steps to reproduce the problem,
- what an attacker can do with it.

You will get a first answer within 7 days. When a fix is ready, a new release and a GitHub security advisory will describe the problem and credit the reporter, if the reporter agrees.
